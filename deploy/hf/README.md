# 田语智农 · 多方言 AI 农技与农田数字孪生平台

面向基层农户的农技服务平台：**拍一张照片、说一句方言**，就能得到病虫害诊断、防治方案与用药提醒，
并把这些能力串成「诊断 — 防治 — 管理 — 收获」的闭环。

> 这是参赛作品的**在线演示实例**。代码仓库见 GitHub（链接由作者补充）。

## 能做什么

| 模块 | 说明 |
|---|---|
| 3D 首页沙盘 | 按省份展示当季病虫害 TOP3，四季切换；底图本地打包，首屏不请求外网 |
| 智能诊断 | 拍照 / 上传图片 + 方言语音 + 文字描述，多模态融合出一份诊断报告 |
| 知识图书库 | 399 张卡片（病害 250 / 虫害 102 / 养护 47），支持关键词与语音检索 |
| 惠农政策 | 农业农村部官网政策原文与摘要，按类型 / 时间筛选 |
| 我的农田 | 田块管理 + 积温生长模拟 + 3D 长势 + 收获期区间预测 |
| 方言语音 | 支持 8 种方言识别与播报（讯飞方言大模型） |

## 关于这个演示实例

- **没有配置语音/大模型密钥**，所以：方言识别、语音播报、大模型成文会**如实降级**
  （改用浏览器朗读、规则模板成文），其余功能不受影响。这是设计上的降级路径，不是故障。
- 推理走 **ONNX Runtime CPU**，单图约 20~30 ms，不需要 GPU。
- Spaces 免费实例**空闲一段时间会休眠**，重新打开时首次冷启动约 1 分钟。

## 技术栈

FastAPI · ONNX Runtime · ChromaDB · YOLOv8（检测）· ResNet50（病害分类）· Three.js · 原生 JS

## 数据与许可

病害识别使用公开的植物病害数据集，虫害检测使用 IP102 数据集，均用于研究与展示。

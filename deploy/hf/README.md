# 田语智农 · 多方言 AI 农技与农田数字孪生平台

面向基层农户的农技服务平台。农户拍摄作物照片或用方言描述症状，平台输出病虫害诊断、防治方案与用药提醒，
并提供当季病虫害地图、知识图书库与惠农政策查询。

本页为 Hugging Face Spaces 的部署说明。在线演示见项目 README 中的演示地址。

## 功能模块

| 模块 | 说明 |
|---|---|
| 3D 首页沙盘 | 按省份展示当季病虫害 TOP3，支持四季切换，底图本地打包 |
| 智能诊断 | 图片、方言语音与文字三路输入，输出融合诊断报告 |
| 知识图书库 | 399 张卡片（病害 250 / 虫害 102 / 养护 47），支持关键词与语音检索 |
| 惠农政策 | 农业农村部官网政策原文与摘要，按类型、时间筛选 |
| 我的农田 | 田块管理、积温生长模拟、3D 长势与收获期区间预测 |
| 方言语音 | 支持 8 种方言识别与播报 |

## 技术栈

FastAPI、ONNX Runtime、ChromaDB、YOLOv8、ResNet50、Three.js。推理在 CPU 上运行，单图约 20–30 ms。

## 数据与许可

病害识别使用公开的植物病害数据集，虫害检测使用 IP102 数据集，均用于研究与展示。

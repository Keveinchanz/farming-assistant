技能接口

平台的两个模型能力按功能封装成独立技能。每个技能都有说明文档、输入输出 JSON Schema、HTTP 接口和命令行入口，可以单独接入其他系统。

后端未启动，以下为离线教程；页面上的可用性状态暂不可用。

快速开始

所有调用都在项目根目录执行。先启动服务，再打开接口文档查看最新 schema。 

# 1. 启动服务
python scripts/20_run_backend.py --no-browser

# 2. 查看技能清单
curl http://127.0.0.1:8000/api/skills

# 3. 接口文档
#    http://127.0.0.1:8000/docs

命令行同样可以调用：python -m skills list、 python -m skills show crop-diagnosis、 python -m skills run <技能名> --input payload.json。

技能一 · 病虫害检测与多模态融合诊断

上传作物照片、方言语音或文字症状，一次返回病害候选、虫害检测框、 融合诊断报告与防治方案。

状态读取中

接口：POST /api/skills/crop-diagnosis 版本：1.0.0

能做什么

  • 病害分类：271 类作物病害，返回 Top-K 候选与置信度
  • 虫害检测：102 类害虫，返回检测框、类群与置信度
  • 语音与文字：方言转写、症状关键词匹配
  • 知识库检索与大模型报告：防治方案、用药提醒、知识库引用

输入

字段说明
image_base64 / image_path图片，二选一。HTTP 只接受 base64，CLI 可用本地路径
audio_base64 / audio_path音频，二选一，可选
audio_formatauto / wav / pcm / amr / mp3
text文字症状描述，最长 4000 字
dialect方言 key，留空使用默认方言
topk病害候选数量，1–10，默认 5

图片、语音、文字至少提供一项。只有图片或只有文字都可以正常诊断。

调用示例

curl -X POST http://127.0.0.1:8000/api/skills/crop-diagnosis \
  -H "Content-Type: application/json" \
  -d '{"text":"水稻叶片有褐色斑点，最近多雨"}'
python -m skills run crop-diagnosis --input payload.json --pretty

输出

  • recognition：病害 Top-K；无图时为 null
  • pest：虫害检测结果；null 表示本次没跑检测，count = 0 表示跑了但没检出
  • report：诊断报告，含防治方案、用药提醒与 source_notes
  • candidates / sources：病害候选与知识库引用
  • degraded：llm / rag / voice / pest 各自的降级状态

技能二 · 农田生长与收获预测

由田块、播种日期与逐日气温计算积温、生育阶段、收获区间和 3D 植株参数。 不登录、不读数据库，可以直接嵌入其他系统。

状态读取中

接口：POST /api/skills/farm-growth 版本：1.0.0

能做什么

  • 有效积温与生育阶段：当前进度、剩余积温、下一阶段
  • 3D 植株参数：株高、叶片数、叶色、穗形态，可直接交给 Three.js 渲染
  • 收获预测：最早、最可能、最晚日期，样本不足时回退积温法
  • 收割建议：推荐收割窗口与注意事项

输入

字段说明
field田块：crop、sow_date 必填；经纬度可选
today计算基准日，默认今天
history逐日气温，元素含 date、tmax、tmin
forecast未来天气，可选
management施肥等管理措施对成熟期的影响
includegrowth / model / harvest / advice / weather

调用示例

curl -X POST http://127.0.0.1:8000/api/skills/farm-growth \
  -H "Content-Type: application/json" \
  -d '{
    "field": {"crop":"水稻","sow_date":"2026-05-01","area_mu":1.2,
              "province":"湖北省","city":"武汉市","lng":114.3,"lat":30.58},
    "today": "2026-10-22",
    "history": [{"date":"2026-08-01","tmax":32,"tmin":24},
                {"date":"2026-08-02","tmax":33,"tmin":25}]
  }'
python -m skills run farm-growth --input payload.json --pretty

输出

  • growth：积温、生育阶段、进度、成熟标记与数据置信度
  • model：3D 植株参数，与农田页使用的是同一结构
  • harvest：收获日期区间、预测方法与样本数
  • harvest_advice / harvest_window：收割建议与推荐窗口
  • degraded：天气、历史气温、收获模型的降级状态

接入 3D 渲染

把返回的 model 直接交给现有的 Three.js 渲染器即可： 

const view = Farm3D.create(canvas, { areaMu: () => 1 });
view.setModel(result.model);

通用约定

  • 两个技能都是公开接口，不需要登录。
  • 请求体上限 30 MB，单个图片或音频解码后上限 20 MB。
  • HTTP 不接受本地文件路径，只接受 base64；命令行两种都支持。
  • 输入错误返回 400，未知技能返回 404，请求体过大返回 413，模型不可用返回 503。
  • 降级不会伪装成成功：degraded 会如实标明哪一路不可用。
